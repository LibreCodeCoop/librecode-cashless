# Glossário inicial PT-BR / EN

| Original | PT-BR | Uso |
| --- | --- | --- |
| Wristband | Pulseira | Suporte físico NFC |
| NFC tag / user tag | Tag NFC | Chip vinculado à conta |
| Account | Conta | Registro que mantém o saldo |
| Balance | Saldo | Valor disponível |
| Top-up / topup | Recarga | Crédito na conta |
| Refund | Reembolso | Devolução de saldo; conferir contexto no upstream |
| Sale / order | Venda / pedido | Operação de consumo |
| Till / POS | PDV / caixa | Terminal ou caixa, conforme contexto |
| Cashier | Operador de caixa | Pessoa autenticada na operação |
| Ticket | Ingresso | Acesso ao evento, diferente de pulseira |
| Receipt | Comprovante | Registro de uma operação |
| Customer portal | Portal do participante | Interface do titular da conta |
| Offline | Sem conexão | Especificar: sem WAN ou sem acesso ao servidor |

Este glossário orienta a tradução futura. Não instala nem substitui arquivos
de tradução do Android ou do painel web.
